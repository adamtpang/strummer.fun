Contact

Choose the path that matches your question.

Strummer is operated by Adam Pang. Public project questions can use the source repository, while personal or business context should use the contact options published on Adam's website.

Technical issues

File reproducible player, Vibe, Tune, accessibility, or browser-compatibility bugs in the Strummer issue tracker. Do not put Spotify tokens, private profile data, audio files, or other sensitive information in a public issue.

Product and operator contact

Use the current contact path at adampang.com for product feedback, collaboration context, or questions that should not be posted publicly. Visiting that site is optional and subject to its own privacy information.

Privacy requests

Strummer Vibe provides profile visibility and deletion controls to the authenticated profile owner. Start with those controls, review the Vibe privacy policy, and use the operator contact path above if the in-product deletion flow does not complete.
